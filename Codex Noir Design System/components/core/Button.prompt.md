Primary call-to-action button — sharp corners, Cinzel small-caps label, gold outline. Use for CV downloads and primary navigation CTAs.

```jsx
<Button variant="primary">Download CV</Button>
<Button variant="ghost">View Projects</Button>
```

Variants: `primary` (filled gold, ink-black text) for the single most important action per view; `ghost` (transparent, gold text/border) for secondary actions. No size prop — one size only, matches the brand's restrained CTA usage.
